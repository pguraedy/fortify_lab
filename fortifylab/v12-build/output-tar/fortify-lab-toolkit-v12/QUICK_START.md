# Fortify Lab Toolkit v12 - Quick Start

Package format: `TAR.GZ`
Source archive: `fortify-lab-toolkit-v12-foundation.tar.gz`

## Extract and install

```bash
tar -xzf fortify-lab-toolkit-v12-foundation.tar.gz
cd fortify-lab-toolkit-v12
sudo ./install.sh
```

Verify:

```bash
fortify-lab --help
```

Launch:

```bash
sudo fortify-lab guided
```

Expected final state: `final-validation PASS`.
