# Fortify Lab Toolkit v12 - Quick Start

Package format: `ZIP`
Source archive: `fortify-lab-toolkit-v12-foundation.zip`

## Extract and install

```bash
unzip fortify-lab-toolkit-v12-foundation.zip
cd fortify-lab-toolkit-v12
sudo ./install.sh
```

Verify:

```bash
fortify-lab --help
```

Launch:

```bash
sudo fortify-lab guided
```

Expected final state: `final-validation PASS`.
